Sprite Layerer

Overview

The 3D Sprite Layerer is a custom Unity editor tool I built over about three weeks to automate the creation of layered sprite prefabs. It was made for a 2.5D prototype where props were built from stacked sprites arranged in 3D space to create a paper-like depth effect — a process that previously meant duplicating sprites, positioning them by hand, and tweaking values one at a time.

With the tool, you provide an array of sprites and it generates a prefab with configurable spacing, angles, and ordering, plus random offsets and variant generation. I designed it with future collaborators in mind, especially artists, so they could import assets and generate usable props without manual scene assembly.

What I did

  • Created a custom Unity editor tool over about three weeks to automate layered sprite prefab creation.
  • Built it to speed up environment creation for a 2.5D prototype that used stacked sprites in 3D space for a paper-like depth effect.
  • Replaced a manual workflow involving sprite duplication, placement, and value tweaking with automated prefab generation.
  • Supported arrays of sprites with configurable spacing, angles, ordering, random positional offsets, variant generation, and save-location control.
  • Designed the tool to be useful for future collaborators, especially artists, so they could generate usable props without manual scene assembly.
  • Improved early prototype workflow by reducing environment setup time and keeping focus on gameplay systems.
