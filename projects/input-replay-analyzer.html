Overview

The Input Replay Analyzer is a standalone WinForms tool I built over four weeks for my Tech Design class. I wanted to work outside of Unity for once and try building something that would actually be useful during playtesting and debugging rather than another thing that only runs inside an engine.

It loads recorded player input logs from playtest sessions, displays them on a timeline, and lets you replay the session locally using the original timestamps. The audience I designed it for is QA testers, user researchers, and designers who need to analyze player behavior, find confusion points, and reproduce bugs reliably.

Goal
Make a playtest session reproducible, so a bug that happened once in front of a tester can be replayed exactly instead of described from memory.

The problem

When debugging playtests, designers usually end up relying on written notes, memory, and incomplete logs. All three have the same problem, which is that they only capture what someone thought was worth writing down at the time, and that's often not the thing that ends up mattering. Reproducing what a player did is close to impossible when you don't know the exact order of their inputs, and a bug nobody can reproduce usually just gets dropped.

So the goal was pretty specific. Let a developer see what the player actually did, pull out one moment from a session, and reproduce a bug reliably by replaying the inputs that caused it.

Core features

Visualization

Input log timeline

Loads recorded logs into a structured timeline so you can see what the player did and when at a glance, instead of reading through raw log lines.

Reproduction

Full session replay

Replays a recorded session locally using the original timestamps, reproducing player behavior exactly as it happened. This is the feature the rest of the tool exists to support.

Analysis

Filtering and trimming

Filter or trim inputs by type or by time range, so you can pull out the thirty seconds that actually matter from a twenty minute session.

Sharing

Cleaned log export

Export trimmed logs so you can hand a specific moment to another developer as a file instead of a paragraph trying to describe it.

Configuration

JSON profile system

Users define custom input maps saved as JSON, letting the tool adapt to different games and control schemes rather than being hardcoded to one project.

Privacy

Executable focus check

Recording only happens while the target application is in focus. Assign the game executable, run the playtest, and unrelated input from outside the game never enters the log.

Example workflow

  1. Assign the game executable so recording stays scoped to it.
  2. Record player input during a playtest session.
  3. Load the recorded log into the tool.
  4. Inspect the timeline and trim to the moment in question.
  5. Replay the session locally to reproduce the bug.

Why WinForms

Building outside a game engine was the whole point. I wanted to see what tool development is like when none of the engine's conveniences are there, which meant handling input capture, log parsing, timestamp syncing, JSON configuration, and the UI myself.

The focus check is the part I'm happiest with, because it came from thinking about the person running the test instead of the person reading the data. Recording every keystroke on someone's machine during a playtest is both a privacy problem and an accuracy problem, and only recording while the game is in focus fixes both without the tester having to remember anything.

Outcome

  • Fully functional input visualization and replay tool.
  • Loads and replays real playtest input logs using original timestamps.
  • Supports multiple games and control schemes through JSON profiles.

What I took from it

I didn't finish every feature I had planned, but the project taught me a lot about input handling, data serialization, and building standalone debugging tools outside an engine. It also reinforced how valuable good tools are for playtesting and iteration, which is why it's something I'd like to come back to.

The most useful playtest data is the kind you can just run again.
