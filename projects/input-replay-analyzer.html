Input Replay Analyzer

Input Analysis & Replay Tool · C# WinForms · Academic
Nov – Dec 2025Tools Programmer & Software DeveloperSolo
I.R.A.

Overview

The Input Replay Analyzer is a standalone WinForms tool I built over four weeks to load, visualize, and replay recorded player-input logs from playtest sessions. I wanted to work outside of Unity and make something genuinely useful for QA testers, user researchers, and designers who need a clearer way to inspect player behavior and reproduce bugs reliably.

The core feature is full input replay: load a recorded log and replay the entire session locally using the original timestamps, reproducing player behavior exactly as it happened. A JSON profile system lets it adapt to different games and control schemes.

What I did

  • Built a standalone WinForms tool over four weeks to analyze recorded player input logs from playtest sessions.
  • Designed it for QA testers, user researchers, and designers who needed a clearer way to inspect player behavior and reproduce bugs.
  • Added timeline-based log visualization with filtering and trimming by input type or time range.
  • Supported exporting cleaned logs so specific moments could be isolated and shared.
  • Implemented full input replay functionality using original timestamps to reproduce sessions locally.
  • Built a profile system where users could define custom input maps and save them as JSON for different games and control schemes.
  • Added an executable focus check so recording only happened while the target app was active, preventing unrelated input capture and helping with privacy and data accuracy.
  • Strengthened my skills in tool development, input handling, data serialization, and standalone debugging utilities outside a game engine.
