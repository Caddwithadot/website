SGP — Streamer Game Project

Twitch-Integrated Interactive Prototype · Unity
Summer 2023Systems Designer & ProgrammerTeam of 2
SGP

Overview

SGP, short for Streamer Game Prototype, was a summer exploration of how Twitch chat could directly drive an in-engine Unity experience. Each chatter spawned an avatar with a floating nametag the moment they sent a message; sending another message reset their lifetime timer and triggered a small hop — turning passive viewers into visible participants in a simulated audience space.

As it grew, I prototyped networking so chatters could control avatars in first person, integrated a public Google Sheet as a username-keyed data store for inventories and cosmetics, built a “!color” customization command, and made an emote parser that spawned particle effects using the emote image as the sprite.

What I did

  • Built a prototype exploring how Twitch chat could directly drive an in-engine Unity experience.
  • Designed and implemented a system that spawned avatars in-scene based on live chat activity, with floating nametags tied to usernames.
  • Added lifetime timers to avatars, resetting them and triggering a hop animation whenever the same chatter sent another message.
  • Prototyped networking so chatters could connect directly to the game and control their own avatars in first person.
  • Integrated a public Google Sheet as a persistent data store keyed by username to support inventories, currency, and cosmetic unlocks.
  • Implemented a command-driven customization system where users could change avatar color using a “!color” command with validated and saved values.
  • Built a dynamic emote parsing system that detected chat emotes and spawned particle effects using the emote image as the sprite.
  • Worked on modular live-data pipelines and readable feedback loops connecting community interaction to gameplay space.
