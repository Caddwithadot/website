Line 9

Overview

Made during the 2025 GMTK Game Jam in 72 hours, Line 9 is a first-person 2.5D inspection game where you examine dolls moving along a conveyor belt that wraps around you, marking anomalies on faulty ones and approving the rest. With fewer programmers on this team, I did more hands-on implementation than in previous jams.

I designed and implemented the core anomaly system and a set of inspection stations that reused one shared framework — a UV lens for hidden marks, a magnifier for stitching detail, and an X-ray for internal components — built to be re-skinned quickly without blowing the 72-hour scope.

What I did

  • Completed a 72-hour GMTK Game Jam project on a remote six-person team.
  • Helped consolidate team brainstorming into a single direction everyone felt good about.
  • Took on more hands-on implementation because the team had fewer programmers than BLOOPS.
  • Designed and implemented the core anomaly system, including randomized doll features and traits flagged as correct or faulty.
  • Implemented a difficulty scaling system where anomalies became subtler as the player improved.
  • Built inspection stations using layer masks to simulate different viewing lenses while reusing a shared system.
  • Created the UV station, magnifier station, and X-ray station, each exposing different anomaly types.
  • Focused on building a flexible framework that could be iterated on and re-skinned without overwhelming the 72-hour scope.
