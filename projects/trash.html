Trash

Overview

Trash is my final academic project at DigiPen, currently still in development. It's a 3D top-down extraction game where the player uses a vacuum gun to suck up trash and materials, then fires them into collectors to complete quotas. Materials can be stored in the ship and spent on upgrades that unlock new mechanics and improve run efficiency.

With only three people on the team, ownership is very direct. I took the primary gameplay role and designed and implemented nearly all core systems, from the navmesh-driven controller to the ScriptableObject-based framework that makes every suckable object modular and expandable.

What I did

  • Took on the primary gameplay role and designed and implemented nearly all core systems.
  • Built the navmesh-based player controller, vacuum gun, suckable object framework, collectors, levers, trash piles, inventory system, quota system, controller support, camera orbit controls, and ship transitions.
  • Added game feel features including screenshake, FOV shifts, and rumble feedback.
  • Implemented the navmesh-driven controller with mouse-facing rotation, directional dash, and “fake” movement via fed position arrays for transitions and possible cinematics.
  • Built the vacuum gun as a layered mechanic with sphere-overlap suction, spiral force, adjustable strength, inventory insertion, clogging behavior, and automatic firing with cooldown ramping.
  • Designed precision-based interaction for levers and collectors using forward raycast targeting and sustained input feedback.
  • Built a ScriptableObject-driven framework for suckable objects with adjustable physics, spiral interaction, break-apart behavior, large-state behavior, firing force, cooldown ramping, and spawn-on-break logic.
  • Designed the quota system around a percentage of total spawned trash, an in-world time limit, early submission rewards, strikes, and soft/hard failure states.
  • Currently developing a charge mechanic that condenses full inventory slots into a single large projectile for faster deposits and deeper decision-making.
